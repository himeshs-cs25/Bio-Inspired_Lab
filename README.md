# 🧬 Bio-Inspired Computing Lab

A collection of Python implementations of bio-inspired optimization algorithms applied to real-world computational and engineering problems.

**Institution:** BMS College of Engineering, Bengaluru  
**Department:** Computer Science and Engineering

## 🚀 Experiments Implemented

| No. | Algorithm | Optimization Problem |
|---|---|---|
| 1 | Genetic Algorithm (GA) | Cloud Task Scheduling |
| 2 | Particle Swarm Optimization (PSO) | Cloud Task Scheduling |
| 3 | Ant Colony Optimization (ACO) | Agricultural Drone Path Optimization |
| 4 | Cuckoo Search (CS) | EV Charging Station Placement |
| 5 | Grey Wolf Optimizer (GWO) | EV Charging Station Placement |
| 6 | Parallel Cellular Algorithm | Smart Streetlight Energy Optimization |

## 🧠 Algorithms Covered

- **Genetic Algorithm:** Evolutionary optimization inspired by natural selection.
- **Particle Swarm Optimization:** Swarm intelligence inspired by collective movement of birds and fish.
- **Ant Colony Optimization:** Optimization inspired by the foraging behavior of ants.
- **Cuckoo Search:** Metaheuristic optimization inspired by cuckoo breeding behavior and Lévy flights.
- **Grey Wolf Optimizer:** Optimization inspired by grey wolf social hierarchy and hunting strategies.
- **Parallel Cellular Algorithm:** Distributed optimization inspired by cellular automata and neighborhood interactions.

## 🛠️ Technologies Used

- Python 3
- NumPy
- Matplotlib (where applicable)
- Jupyter Notebook / Google Colab

## 📂 Repository Contents

Each experiment includes:
- Problem Statement
- Objective
- Algorithm / Pseudocode
- Python Implementation
- Sample Output

## 🎯 Learning Outcomes

- Implement evolutionary and swarm intelligence algorithms.
- Apply nature-inspired techniques to real-world optimization problems.
- Explore parallel and distributed computational approaches.
- Understand optimization strategies for scheduling, path planning, infrastructure placement, and energy management.
